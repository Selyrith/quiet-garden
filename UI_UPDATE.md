# Гайд по новому интерфейсу Quiet Garden

Интерфейс полностью переведён из «технического» стиля в **«Магический дневник садовника»**. 
Основные изменения касаются эстетики: цвета, шрифты, текстуры.

## Что поменялось

### 1. Главное меню (index.html)
- Убран плоский синий фон. Заменён на CSS-градиент, имитирующий дерево.
- Кнопки слотов теперь выглядят как вывески на деревянных дощечках (с внутренними тенями и золотой обводкой при наведении).
- Добавлены шрифты `Merriweather` (заголовки) и `Nunito` (текст).
- Поле ввода кода теперь выглядит как пергаментный свиток с золотой рамкой при фокусе.

### 2. Верхняя панель (HudTopBar.js)
- Фон теперь тёмно-коричневый с текстурой досок.
- Счётчик монет выглядит как прикреплённая пергаментная бирка.
- Код комнаты — это табличка из тёмного дерева с золотой гравировкой.

### 3. Инвентарь (InventoryBar.js)
- Панель теперь выглядит как деревянная полка.
- Каждый слот семени — это отдельная деревянная коробочка. 
- Выбранное семя подсвечивается зелёным с золотой рамкой (вместо плоского синего).

### 4. Кнопки инструментов (GameSceneUi.js)
- Убраны плоские серые прямоугольники.
- Теперь это круглые «каменные» печати (в неактивном состоянии — тёмное дерево).
- Выбранный инструмент подсвечивается ярко-зелёным с золотой обводкой и слегка увеличивается (эффект объема).

### 5. Оверлеи (Магазин, Улучшения, Книга, Цели)
- Все панели переведены на **стиль пергамента**: светлый фон `#f5e6c8`, коричневый текст `#3e2723`.
- Заголовки используют сказочный шрифт `Georgia, serif`.
- Кнопки покупки/действий теперь зелёные с золотой обводкой.
- Вместо резких белых линий — мягкие коричневые рамки.

### 6. Уведомления (Toast)
- Теперь они появляются в виде деревянных свитков с золотым текстом.

## Что НЕ изменилось (и почему)
- **Логика взаимодействия**: нажатия, драг, отправка событий на сервер — всё осталось прежним.
- **Игровое поле**: сетка 8х8, процедурные растения и анимации остались нетронутыми.

## Как это работает технически
- В `HudTopBar.js`, `GameSceneUi.js` и оверлеях вместо плоских `fillStyle` и `fillRect` используются `Graphics` с `fillRoundedRect`, а также `lineStyle` для создания рамок и обводок.
- Для кнопок используется "невидимая зона клика" (`rectangle` с прозрачностью `0.001`), чтобы визуальная часть (`Graphics`) не мешала интерактивности Phaser.
- `InventoryBar` перерисовывает полку при ресайзе.
