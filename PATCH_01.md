# Patch 01 — сеть, звук, пауза

Патч по итогам аудита HTML5 Game Craft. Изменения минимальные, чтобы не риска сломать существующую игру. Ниже — что именно поменялось и как проверить.

## Что исправлено

### 1. Эмоции приписывались не тому игроку — `server/emotes.js`

**Было:** broadcast уходил с `socket.id`, клиент сравнивал с `auth.playerId`. Свой эмодзи никогда не показывался со своим цветом; чужой — со случайным.

**Стало:** broadcast уходит с `auth.playerId || socket.id` — как везде в проекте.

**Проверка:** открой две вкладки в одной комнате, отправь эмодзи с одной — увидишь его над персонажем с корректной атрибуцией.

### 2. Двойной `join-room` при первом входе и reconnect — `src/main.js`

**Было:** при `socket.connected === false` вызывался `socket.once('connect', emitJoin)`, и параллельно работал глобальный `socket.on('connect', ...)`. Два join → два `initial-state`, два `room-code` (harmless, но грязно).

**Стало:** единственный источник правды — глобальный `on('connect')`. Если `socket.connected` — emit сразу. Иначе `socket.connect()`, а join выполнит глобальный обработчик.

**Проверка:** DevTools → Network → WS → в логе должно быть ровно одно `join-room` на вход.

### 3. Музыка играла в свёрнутой вкладке — `src/audio/SoundManager.js` + `MusicManager.js`

**Было:** Phaser сам останавливает rAF, но Web Audio продолжает играть. MusicManager планировал ноты через `setTimeout` — при возврате прилетала пачка нот с одинаковым `currentTime`.

**Стало:**
- `SoundManager.pause()` — останавливает музыку и приостанавливает `AudioContext`.
- `SoundManager.resumeFromPause()` — возобновляет контекст и музыку (если не выключено кнопкой mute).
- `MusicManager` переписан на **lookahead-планировщик** (Advanced, Шаг 13): ноты создаются на абсолютное время, тик — раз в 25 мс, lookahead — 150 мс вперёд. Никакого джиттера.

**Проверка:** сверни вкладку на 30 секунд, вернись — не должно быть «догоняющих» нот. Музыка плавно продолжится.

### 4. Утечка слушателя на `resize` — `src/scenes/GameScene.js`

**Было:** `this.scale.on('resize', ...)` висит на глобальном ScaleManager. При смене сцены (что мы сейчас вводим) — накапливается по одному обработчику за рестарт.

**Стало:** в `shutdown` — `this.scale.off('resize', onScaleResize)`. Аналогично для `document.addEventListener('visibilitychange', ...)` и `time.removeAllEvents()`.

**Проверка:** в консоли DevTools `getEventListeners(window)` — количество `resize` стабильно при повторных заходах.

### 5. Пауза + ESC + потеря фокуса — `src/scenes/PauseScene.js` (новый), `GameScene.js`, `HudTopBar.js`

**Было:** паузы не было вообще. При потере фокуса игра продолжалась молча.

**Стало:**
- Новая `PauseScene` — параллельная сцена с оверлеем «Продолжить / В меню».
- Кнопка `⏸` в top bar (между mute и menu).
- `ESC` — пауза/резюм.
- `visibilitychange → hidden` — автоматическая пауза + стоп музыки.
- `visibilitychange → visible` — пользователь видит экран паузы, а не «прыжок» в середину.

**Проверка:**
1. Нажми `⏸` — игра встала, музыка остановилась.
2. Нажми `ESC` — вернулся в игру, музыка пошла.
3. Сверни вкладку на 10 секунд — при возврате видишь экран паузы.
4. Сверни вкладку прямо из паузы — вернёшься в паузу.

### 6. `prefers-reduced-motion` — `GameScene.js`

**Было:** атмосферные частицы (лепестки, светлячки, дождь) крутились всегда.

**Стало:** если `matchMedia('(prefers-reduced-motion: reduce)').matches` — WeatherEffects и AmbientEffects заменяются на no-op. Тинт мира и геймплей не затронуты.

**Проверка:** DevTools → Rendering → Emulate CSS media feature `prefers-reduced-motion: reduce`. Частиц нет, тинт времени суток работает.

### 7. Guard в `MutationsOverlay` — `src/ui/MutationsOverlay.js`

**Было:** `mut.mult.toFixed(1)` падал при `mut === null` (out-of-range индекс).

**Стало:** `if (unlocked && mut)`.

## Что НЕ вошло в патч

- **DPR-масштаб (Retina)** — требует либо `Scale.FIT` с виртуальным разрешением (что меняет раскладку всей сцены), либо ручного `ctx.scale` в рантайме. Рискованно без живого теста на телефоне. Рекомендуется отдельным патчем.
- **BALANCE файл** — нужно вынести ~15 констант из 6 файлов в `shared/balance.js`. Отдельный проход.
- **i18n** — строки по-прежнему в коде. Не критично, но DoD п.12 не закрыт.
- **Серверный авторитет** — сервер уже авторитетный (все проверки на бэкенде), DoD п.17 закрыт по умолчанию.

## Как применить

1. Замени файлы в проекте.
2. `npm start`.
3. Прогони чек-лист выше.

## Что показать в README проекта

Изменения затрагивают только клиент и одну функцию на сервере. Никаких миграций данных нет — `data/rooms.json` не трогается.
