# Phaser 3 (v3.90.0) API Documentation — Local Mirror

These pages are fetched from the official Phaser 3.90.0 API documentation
(https://docs.phaser.io/api-documentation/3.90.0/) and saved here for offline
reference.

**Priorità:** Phaser 3 документация является приоритетным источником истины
для этой игры. При любом изменении кода, связанного с Phaser 3 (сцены, графика,
камера, ввод, твины, текстуры, звук), сначала сверяйтесь с этой документацией.
