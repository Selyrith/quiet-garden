# Quiet Garden — референсы для улучшения графики (веб-движок Phaser 3)

Папка — источник истины для графических улучшений. Собрано 2026-11-13.
Движок в проекте: **Phaser 3.90.0**, рендер `Phaser.AUTO` (WebGL с фолбэком на Canvas).

Правила, выведенные из документации и проверяемые на нашем коде:

1. **FX только в WebGL.** `preFX`/`postFX` — шейдеры, в Canvas-режиме молча не работают.
   Значит: любой эффект обязан иметь графический/Canvas фолбэк (как сейчас сделано у виньетки).
2. **Graphics нельзя перевести на `Light2D`** — Light-пайплайн не поддерживает Graphics/Shape
   (цитата из `LightsPlugin`: «you cannot use this pipeline on Graphics Game Objects or Shape Game Objects»).
   Значит почва/грядки должны быть **текстурами** (Image), а не `Graphics`, если хотим свет.
3. **`preFX.addGlow` — известный тормоз.** В issue #6393 glow на 1024×896 давал 8 fps.
   Для «свечения» дешевле: аддитивный спрайт-ореол (blend ADD) + точечный `PointLight`.
4. **Максимум 10 источников света** на камеру (`maxLights` в конфиге рендера, по умолчанию 10,
   менять можно только в конфиге игры — не в рантайме). Лишние отбрасываются по расстоянию от центра.
5. **Статику — в текстуры.** Всё, что не меняется (фон, hills, рамка сада, дорожки), надо один раз
   нарисовать в `DynamicTexture` и показывать одним `Image`. Сейчас фон перерисовывается
   `Graphics` и перекрашивается полосами при каждой смене фазы дня.
