# Сводная таблица техник: что, зачем, почём

Приоритеты: **P1** — сделать первым (максимум эффекта за минимум риска),
**P2** — заметное улучшение, чуть больше работы, **P3** — «если останется время».

Цена — по шкале: `низкая` (не влияет на FPS/размер), `средняя` (разовые затраты при
создании или ограниченное число объектов), `высокая` (per-frame шейдеры, много объектов).

## Порядок внедрения (план)

1. **Обвязка**: helper `bakeTexture(scene, key, w, h, drawFn)` с кэшем по ключу (A6).
2. **A1 + A2** — фон в текстуры. Проверка: сцена выглядит так же, `Graphics`-объектов меньше.
3. **A3 + A4** — рамка/дорожки и почва в текстуры. Это визуально самый заметный шаг.
4. **B1 + B2** — свет фонарей и ореолы. Вечер/ночь — видно сразу.
5. **C1** — ветер порывами (5 строк, но убирает «шум»).
6. **D1, D3** — отклик полива/ошибки.
7. Далее — по остаточному принципу: C2, C3, C6, D2, E2/E3.

## Стоп-лист

- Light2D, bloom/glow на грядках и растениях.
- Растровые спрайты растений из интернета вместо процедурных 300 текстур.
- Тяжёлые `Graphics` в `update()` (сейчас только `updateGrassWind` двигает готовый объект — это ок).
