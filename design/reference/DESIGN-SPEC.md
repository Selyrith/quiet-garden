# Дизайн-референс: Dawnfield (cozy farming life, mobile-first)

Источник: <https://dawnfield.lovable.app/ui> (UI/UX Design Spec, Hay Day–inspired).
Скачано 2026-11-13. Файлы: `dawnfield-tokens.css`, `_raw-extract.json`.

Это **единственный** источник истины для визуала Quiet Garden. При расхождении
со старым кодом — правим код, а не референс.

## 2. Правила цвета (Color Rules)

1. **60-30-10**: 60% тёплые нейтрали (Cream/Soil), 30% зелень (Forest/Meadow),
   10% акценты (Gold/Terracotta/Blossom).
2. **Ни чистого чёрного, ни чистого белого.** `#000` → Rich Soil `#3D2E20`,
   `#FFF` → Sunlit Cream `#F7F1E6`.
3. **Тёплый уклон**: даже холодные тона (Sky, Winter) уводят в янтарный.
4. **Потолок насыщенности — 85%.** Ни один цвет не ярче: сохраняет «акварель».
5. **Контраст**: WCAG AA — 4.5:1 для body, 3:1 для крупного текста.

## 3. Типографика

| Роль | Шрифт | Применение |
|---|---|---|
| Display / Headers | **Lilita One** | заголовки, названия, кнопки, крупные числа |
| Body / Readable | **Nunito** (400–700) | описания, диалоги, системный текст |

Оба — rounded, «тёплые». Никаких Inter / DM Sans / Georgia в UI.

## 4. Сетка и размеры

- **База сетки: 8dp.**
- **Touch target: 56×56dp минимум** (Apple HIG 44pt, Material 48dp — превышаем оба).
- **Отступ: 16dp** стандарт, 8dp между кнопками.
- **Панели**: радиус 24px, тень 8–12px blur, **тёплая** (не чёрная).
- Тулбар: капсула с радиусом 16dp, **плавает в 12dp над нижним краем**.

## 5. Слои экрана (Screen Stack Model)

| Слой | Содержимое | Затемнение мира |
|---|---|---|
| 0 | Игровой мир (всегда рендерится, никогда не скрыт полностью) | — |
| 1 | HUD (часы, энергия, валюта, тулбар) | — |
| 2 | Нижние листы (инвентарь, крафт, магазин) | до 60% |
| 3 | Модальные диалоги (подтверждения, алерты) | лист до 40% |
| 4 | Тосты / подсказки | — |

## 6. Кнопки и контролы

| Состояние | Правило |
|---|---|
| Primary | Forest green + 2px emboss, «вдавленная доска» |
| Secondary | Harvest gold + лёгкая текстура |
| Destructive | Terracotta + «danger stripe» в углу |
| Pressed | сдвиг внутрь на 2px + затемнение на 10% |
| Hover / Focus | тёплое кольцо 4px, янтарное (**не синее**) |
| Min touch target | **56×56dp** |

## 7. Motion

- Активный инструмент: scale 110% + мягкий «bouncy» (spring stiffness ~300).
- harvesting/награда: 8–12 искр вверх, 0.4s, мягко.
- «Silence is a Sound»: тихие паузы, чтобы акценты звучали.
- Тест «бабушки»: если бабушка улыбнулась, нажав кнопку — сделано правильно;
  если вздрогнула — перебор.

## 8. Звук

Материальный sound design (дерево, земля, металл, жидкость), ±5% случайного
питча на каждый SFX. Никаких чистых синтетических тонов.

Адаптивная музыка (6 стемов): Bed / Harmonic / Melodic / Rhythmic / Accent / Ambience.
Кроссфейд между 5 настроениями времени суток (Dawn / Day / Afternoon / Dusk / Night).

## 9. Доступность

- WCAG 2.1 AA.
- UI scale 80% → 150%.
- One-hand mode: тулбар зеркалится на любую сторону.
- Long-press: 150ms → 600ms настраивается.
- Touch target override до 64×64dp в режиме доступности.
- Icons: 16×16 пиксель-арт с 1px тёмным контуром, показ 2× / 3×.

## 10. Что берём в Quiet Garden

Применяем: палитру, 60-30-10, запрет чистого #000/#FFF, Lilita One + Nunito,
56dp touch target, 8dp сетку, тёплые тени, слоистую модель экранов, 6-стильный
тулбар, материальный звук, «Silence is a Sound».

Не применяем (не наш жанр): пиксель-арт иконки 16×16, животноводство, NPC-диалоги,
сезоны/погода как механика.
